# Android 真机验收清单

- 在 ARM64 Android 10+ 设备执行 `adb install -r`，确认安装成功且应用可启动。
- 导入 UTF-8 的 Markdown 和 TXT，重启应用后确认书籍、大纲和阅读位置仍存在。
- 保存 DeepSeek Key，生成一节卡片，确认章节概览位于该节概念卡片之前。
- 阅读当前节时确认下一节立即进入生成状态，并显示进度。
- 上下滑动卡片，检查收藏、复制、LaTeX 公式和卡片绑定追问。
- 在设置页预加载离线中文模型，分别试听中文女声、中文男声和 0.2 至 2.0 倍语速。
- 点击卡片朗读，确认只读标题、一句话和通俗解释；点击寓言按钮，确认只读寓言。
- 第二次朗读相同内容，确认命中本地 WAV 缓存且启动明显更快。
- 关闭网络后再次朗读已缓存内容与新内容，确认离线语音仍可工作。
